## What this repo is

The source for every explainer I have delivered: one folder per video, named
`MMDDYYYY-topic` by the Friday of the week it was built. Each folder has a
report, the week's Frictional log, a readable beat sheet, the narration script,
process notes, and the source files (`beat_sheet.json`, `scenes.py`,
`STATUS.md`). Videos live on Drive, not in git.

**Built** is the week the video was made (weeks run Monday–Sunday): the week
from my notes, or earlier where the build record shows it was finished sooner.
For most of videos 01–14 the first cut was 1080p and was re-rendered in 4K around
21 Sep – 4 Oct; each folder's FRICTIONAL.md gives both dates. **Delivered** is
the date it was uploaded to the Drive review folder.
